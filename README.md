# Frontend Mentor - Blog Preview Card Solution

This is my solution to the **Blog Preview Card** challenge on Frontend Mentor. The challenge was to build a responsive blog card component that closely matches the provided design.

## Overview

The Blog Preview Card displays a featured article with its category, publication date, title, description, and author information. The layout is fully responsive and adapts well across different screen sizes.

- Responsive card layout
- Clean semantic HTML structure
- Hover effect on the article title
- Custom typography using Google Fonts
- Author section with avatar
- Modern card shadow and rounded corners

## What I Learned

During this project I practiced:

- Writing semantic HTML using `<main>`.
- Building responsive layouts with `max-width`.
- Centering content using CSS Grid.
- Creating hover effects for links.
- Using Flexbox to align author information.
- Applying spacing, shadows, and border radius to create a clean UI.
